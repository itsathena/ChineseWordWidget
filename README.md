# ChineseWordWidget

A simple iOS Lock Screen widget that helps you learn Chinese vocabulary throughout the day.

### Features

* Lock Screen widget
* Refreshes every 30 minutes
* Shows a new Chinese word
* Built with SwiftUI and WidgetKit
* Works with locally stored vocabulary

### Built With

Swift · SwiftUI · WidgetKit · Xcode

### Goal

**Learn one new Chinese word every 30 minutes.**
